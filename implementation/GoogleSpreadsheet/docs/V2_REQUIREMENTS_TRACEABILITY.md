- Baseline date: 2026-07-24
- Repository: `GoogleSpreadsheet`
- Controlling instructions: `CODEX_PHASE1_AUDIT_PHASE2_TO_4_INSTRUCTIONS.md`, `CODEX_PHASE5_TO_7_INSTRUCTIONS.md`
